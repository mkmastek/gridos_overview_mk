# Fonts

The deck embeds two typefaces named in the Mastek Brand Book (2023):

| Font | Used for | Licence |
|---|---|---|
| Titillium Web (400, 600, 700) | Titles, headings, highlights | SIL Open Font License 1.1 |
| Poppins (400, 500, 600) | Paragraphs, captions, numbers | SIL Open Font License 1.1 |

Both were downloaded from Google Fonts (Latin subset, WOFF2) and are embedded in the
single-file build so the deck works offline. The SIL Open Font License 1.1 allows the fonts
to be bundled and redistributed with software: https://openfontlicense.org

- Titillium Web — © Accademia di Belle Arti di Urbino and students of MA course of Visual design
- Poppins — © Indian Type Foundry

If a font cannot load, the deck falls back to Trebuchet MS, as the Brand Book recommends.
